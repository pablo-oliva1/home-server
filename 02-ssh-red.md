- Comprobación de configuración de red.

## Comprobación de configuración de red

Comprobar configuración de red actual:

```bash
sysadmin@servidor:~$ sudo cat /etc/network/interfaces

# This file describes the network interfaces available on your system
# and how to activate them. For more information, see interfaces(5).

source /etc/network/interfaces.d/*

# The loopback network interface
auto lo
iface lo inet loopback

# The primary network interface
allow-hotplug wlp2s0
iface wlp2s0 inet dhcp
        wpa-ssid ########
        wpa-psk  ########
```

COmprobar puerta de enlace:
```bash
sysadmin@servidor:~$ ip route

default via 192.168.1.1 dev wlp2s0 proto dhcp src 192.168.1.135 metric 3003 
192.168.1.0/24 dev wlp2s0 proto dhcp scope link src 192.168.1.135 metric 3003 
```

Comprobar servidores DNS en uso:
```bash
sysadmin@servidor:~$ cat /etc/resolv.conf

# Generated by dhcpcd from wlp2s0.dhcp, wlp2s0.dhcp6, wlp2s0.ra
# /etc/resolv.conf.head can replace this line
nameserver <dns1>
nameserver <dns2>
nameserver fe80::1%wlp2s0
# /etc/resolv.conf.tail can replace this line

```

Conclusiones:
- La interfaz en uso es `wlp2s0`.
- La puerta de enlace es `192.168.1.1`.
- La ip actual es `192.168.1.135`, asignada por DHCP.

## Establecer una IP fija

Hacer respaldo del archivo de red:
```bash
sysadmin@servidor:~$ sudo cp /etc/network/interfaces /etc/network/interfaces.bak
```

Instalar el paquete *resolvconf*.

> Es un paquete de gestión de servidores DNS, se puede leer sobre él con `man resolvconf`.
> - El sistema siempre mira los DNS de /etc/resolv.conf, donde *dhcpcd* los escribe con los que da el router.
> - Al poner una IP fija *dhcpcd* no actúa, con `resolvconf` este lee la configuración de /etc/network/interfaces y la copia en `resolv.conf`

```bash
sysadmin@servidor:~$ sudo apt install -y resolvconf
```


Comprobar que se mantiene la conectividad (salida recortada):
```bash
sysadmin@servidor:~$ ping -c 3 google.com

--- google.com ping statistics ---
3 packets transmitted, 3 received, 0% packet loss, time 2004ms
```

Editar */etc/network/interfaces*:
```bash
sysadmin@servidor:~$ sudo nano /etc/network/interfaces

# The primary network interface
allow-hotplug wlp2s0
iface wlp2s0 inet static
        address 192.168.1.250/24
        gateway 192.168.1.1
        dns-nameservers <dns1> <dns2>
        wpa-ssid ########
        wpa-psk  ########
```
Notar que:
- Se sustituye *dhcp* por *static*.
- Se fija la IP en 192.168.1.250, y la puerta de enlace en 192.168.1.1.
- Fija <dns1> como primer servidor DNS y <dns2> como el segundo.

Aplicar IP fija: reiniciar.

### Comprobación

Que se mantiene la IP fija (salida recortada):

```bash
sysadmin@servidor:~$ ip -br a

enp3s0           DOWN           
wlp2s0           UP             192.168.1.250/24
```

Que se tiene acceso a internet (salida recortada):

```bash
sysadmin@servidor:~$ ping -c 3 debian.org
```
